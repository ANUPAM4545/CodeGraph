# Product Vision

CodeGraph is an AI-powered codebase intelligence platform that converts complex software repositories into a machine-understandable code knowledge graph.

## Core Features
1. Connect a GitHub repository.
2. Analyze its source code.
3. Understand its architecture.
4. Explore dependencies.
5. Search code semantically.
6. Ask natural-language questions about the repository.
7. Trace execution and data flows.
8. Visualize the architecture in 2D.
9. Explore the codebase through an interactive 3D visualization.
10. Analyze the potential impact of changing a piece of code.

## Long-term Experience
"Google Maps + IDE intelligence + architectural knowledge graph for software systems."

The system relies on a structured representation of the repository (AST -> Symbols -> Relationships -> Graph) as the core source of truth, avoiding pure LLM hallucination.
